# Listening Module

One of the primary objectives of `OpenScofo` is to expand the range of sonic capabilities supported by score-following systems. In particular, the framework is designed to accommodate complex timbral events, including extended and percussive instrumental techniques, which are often insufficiently represented in traditional score-following approaches.

To support this objective, `OpenScofo` integrates a machine learning module based on the `ONNX` runtime and `libonnx`. This module allows models to be trained and deployed for the recognition and classification of diverse sound events. Through this mechanism, the system can be adapted to a wide variety of sonic materials and performance contexts.

The following section presents the set of audio descriptors employed during the training process, together with their corresponding mathematical formulations. These descriptors form the feature representation used by the machine learning models within the `OpenScofo` framework that can be used with the `py.train-onnx` object or the `train` model for Google available via `OpenScofo` Python module.

For easy integration with languages used for AI trained like Python, `OpenScofo` descriptors tries to be compatible with `librosa` and `essentia`. `librosa` is the main choid, because it is great for spectral descriptors, but lacks a lot of others descriptors. `essentia` is more complet but less used is seems messy.

* Descriptors compatible with `librosa` are marked with the icon: :custom-librosa:.

* Descriptors compatible with `essentia` are marker with: :custom-essentia:.
